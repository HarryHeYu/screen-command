# Screen Command

[English](README.md) | [简体中文](README.zh-CN.md)

Select any region on your screen and instantly act on it — OCR, translate, extract code, explain errors — with the result ready to copy.

It collapses the usual "take a screenshot → save it → open a tool → upload → paste → type a command" loop into a single interaction: see it, select it, use it.

## Features

- **Region capture**: drag a rectangle on a full-screen dimmed overlay, with live selection size and Esc to cancel. Multi-monitor and DPI scaling aware.
- **Local OCR**: powered by the built-in Windows OCR engine (Windows.Media.Ocr). English and Chinese, fully offline.
- **Action system**: OCR, copy text, translate, extract code, convert to Markdown, explain errors, save image — chosen from a floating menu with number-key shortcuts.
- **Error explanation**: offline rule-based analysis of captured error output (Python tracebacks, CUDA OOM, git, Node.js, MSVC/MinGW, shell errors). Optional LLM enhancement.
- **Quick action**: `Ctrl+Shift+1` captures, OCRs, and copies to the clipboard without opening the menu.
- **Test harness**: run any action on an image file from the CLI — automated tests don't need a real screen.

## Setup

Requires Python 3.11–3.13 on Windows 10 1809+. All dependencies live in a project-local virtual environment; nothing is installed system-wide.

```bash
cd screen-command
python -m venv .venv
.venv\Scripts\python -m pip install -e .

# Run
.venv\Scripts\python -m screen_command run
```

After the app starts, press `Ctrl+Shift+A` to start a capture, or click the Capture button in the status window. Hotkeys are registered at process lifetime only — the app leaves no persistent changes behind. If a hotkey is taken by another program, registration fails with a visible hint and the Capture button still works.

## CLI

```bash
screen_command run            # launch the GUI
screen_command providers      # list available OCR providers and language packs
screen_command process <img> --action ocr|copy_text|translate|code|markdown|explain|save_image
    [--provider auto|windows|mock] [--language zh-Hans-CN]
    [--output result.txt] [--md] [--opt KEY VALUE ...]
```

## Hotkeys

| Hotkey | Action |
|---|---|
| `Ctrl+Shift+A` | Select a screen region, then pick an action |
| `Ctrl+Shift+1` | Select → OCR → copy to clipboard |

## Tests

```bash
.venv\Scripts\python -m pytest tests -v       # unit + integration tests
.venv\Scripts\python scripts/e2e_smoke.py     # full-pipeline smoke test on a real screen
```

Test images are generated by `tests/make_fixtures.py` (English / Chinese / mixed / terminal error / code / small text).

## Accuracy notes

Translate, extract code, convert to Markdown, and explain errors are bounded by raw OCR quality; the rule-based post-processing (indentation reconstruction, full-width normalization, line-number stripping) does not correct characters. Small monospace terminal fonts have typical confusions (`l↔1`, `O↔0`). For best results select a larger region and avoid tiny or low-contrast text. A selection spanning multiple monitors is cropped from the monitor under the selection center.

## Privacy

Local-first by default: capture and OCR never leave your machine and the app contains no networking code. Translate and LLM actions are built on provider abstractions with no bundled implementation; unconfigured actions show an explicit "unavailable" message and everything else keeps working.
